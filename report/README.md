# Analysis Report

This folder contains the full analytical report for the Cyclistic bike-share case study.

## Report

**`Case Study Report_Bike_Share_Analysis.pdf`**

The report presents the methodology, analysis, visualizations, findings, and interpretation of differences between casual riders and annual members during **July 2025–June 2026**.

The analysis covers:

* Membership composition
* Ride duration
* Day-of-week patterns
* Hourly riding patterns
* Monthly and seasonal patterns
* Bike type
* Station and location patterns
* Overall behavioral differences between casual riders and annual members

The report provides the detailed analysis behind the findings summarized in the main project `README.md`.
