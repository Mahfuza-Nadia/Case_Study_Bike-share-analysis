# SQL Analysis

This folder contains the SQL queries used to prepare and analyze the Cyclistic bike-share trip data in Microsoft Access.

## Analysis Queries

**`analysis_queries.sql`**

The queries document the main analytical steps used in the project, including:

* Combining monthly datasets
* Calculating total rides
* Comparing casual and member rides
* Calculating average ride duration
* Analyzing ride-duration categories
* Examining rides by day of week
* Examining rides by hour
* Examining monthly riding patterns
* Comparing bike types
* Checking station data quality
* Analyzing station-level riding patterns

The queries were developed and executed in **Microsoft Access** using the combined trip dataset.
