# Tableau Workbook

This folder contains the Tableau workbook used to create the visualizations and dashboard for the Cyclistic bike-share analysis.

## Workbook

**`Case_Study_Rider-Behavior-Analysis.twbx`**

The packaged Tableau workbook contains the visualizations and dashboard developed for this project.

The dashboard presents differences between casual riders and annual members across:

* Overall ride volume
* Ride duration
* Day of the week
* Time of day
* Monthly and seasonal patterns
* Bike type
* Station-level usage

## Interactive Dashboard

The interactive version of the dashboard is published on **Tableau Public**.

The Tableau Public link is available here in `README.md`.
